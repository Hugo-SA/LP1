# LP1

Testes com Java e JUnit

Este repositório foi feito para documentar exercícios realizados na aula de "Linguagens de Programação 1" utilizando Java e JUnit com o objetivo de estudar programação orientada a objetos, modelagem de sistemas e realizar testes automatizados substituindo o uso de println para validação de resultados.

Ao invés de verificar saídas manualmente no console, os testes garantem que o comportamento do código esteja correto de forma mais organizada, confiável e escalável.
